# Suman Poojary — Portfolio

A responsive, static portfolio featuring five selected projects. Built with plain HTML, CSS, and JavaScript, with no build step or runtime dependencies.

## Publish

GitHub Pages serves the root of the `main` branch. Push updates to `main` to publish them; no build step is needed.

## Edit

- `index.html` — page content, project descriptions, and repository links
- `styles.css` — responsive layout and visual design
- `script.js` — small scroll-reveal interaction

Project visuals are custom CSS illustrations and interface mockups made for this portfolio.
